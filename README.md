# HorizonLink

**HorizonLink** is an open-source Python research sandbox for exploring information transmission near horizons and in quantum-channel analogues.

The project separates established physics, toy models, and clearly labeled speculative experiments. It does **not** claim faster-than-light communication or signaling out of a classical black-hole event horizon.

## Research tracks

- Classical absorption and redshift near horizons
- Noisy Gaussian and erasure-channel analogues
- Stimulated-emission toy models
- Hayden–Preskill-inspired information recovery experiments
- Teleportation / traversable-wormhole circuit analogues
- Laboratory analogue-horizon simulations
- Information-theoretic metrics and hypothesis search

## Goals

1. Make horizon-communication ideas testable as code rather than vague claims.
2. Separate known physics from assumptions and speculative extensions.
3. Provide reproducible experiments, metrics, plots, and notebooks.
4. Search parameter spaces for regimes that preserve recoverable information.
5. Keep the code approachable enough to extend collaboratively.
