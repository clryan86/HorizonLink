# Scientific assumptions and labeling rules

HorizonLink uses three labels.

## 1. Established

Standard results used within their normal assumptions, such as the Schwarzschild radius, gravitational redshift outside the horizon, binary erasure-channel capacity, and Shannon-Hartley capacity.

## 2. Analogue / toy model

Mathematical models that borrow structure from a physical problem without claiming to reproduce a real black hole. The current Hayden-Preskill recovery module is in this category.

## 3. Speculative

Hypotheses that go beyond established evidence. These are welcome as testable code experiments, but must be explicitly labeled and must include a proposed falsification or comparison test.

## Core guardrail

A classical event horizon is one-way: no known classical signal sent from inside it reaches an outside observer. HorizonLink therefore focuses on outside-horizon signaling limits, information-recovery theory, analogue systems, and clearly identified speculative extensions.
